# 📰 Blog Management System (Frontend)

This is the **React.js frontend** for the Blog Management System. It connects to the Node.js + Express backend, supports user authentication, blog CRUD operations, search, and pagination using **Redux Toolkit** with `createAsyncThunk`.

---

## 🚀 Features

- JWT-based authentication (Login/Register)
- Redux Toolkit for state management
- Blog listing with pagination
- Create, Edit, Delete blog posts
- Search blogs by keyword
- Responsive design with plain CSS (no framework)

---

## ⚙️ Tech Stack

- **React.js**
- **Redux Toolkit**
- **React Router DOM**
- **Axios** for API requests
- **JWT** (via localStorage)
- **Plain CSS** for styling
