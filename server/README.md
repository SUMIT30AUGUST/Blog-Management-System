# 📰 Blog Management System (Backend)

This is the backend API server for the Blog Management System built with **Node.js**, **Express.js**, and **MongoDB**. It supports JWT User authentication, blog CRUD operations, and image uploads.

---

## 🚀 Features

- User Register and Authentication (JWT)
- Create, Read, Update, Delete blogs
- Image upload (via Multer)
- Search functionality
- Pagination

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB** with **Mongoose**
- **JWT** for authentication
- **Multer** for image uploads
- **dotenv** for environment configuration
